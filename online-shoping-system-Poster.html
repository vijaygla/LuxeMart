1. Executive Summary & Context

OVERVIEW

Modern high-end e-commerce requires bridging three traditionally disconnected paradigms: rigid transactional integrity (orders, stock, and payments), frictionless interactive browsing with micro-interactions, and intelligent conversational assistance that never hallucinates unstocked products or invalid pricing.

  • Stateless Micro-Services Gateway: Built on Python 3.12 FastAPI with async I/O and Pydantic v2 validation contracts.
  • Signals-Driven Reactive Client: Angular 21 with Standalone components, Zoneless signals, SSR hydration, and SCSS tokens.
  • High-Fidelity Enterprise Persistence: Microsoft SQL Server 2022 backed by SQLAlchemy 2.0 and PyODBC with connection pooling.

7. Security, RBAC & NFRs

COMPLIANCE
  • Cryptographic Passwords: Irreversible Bcrypt salt hashing protects against rainbow table exploits.
  • Role-Based Access Control: Dual-layer route guards in Angular (adminGuard) paired with FastAPI dependency injection (get_current_admin).
  • SQL Injection Immunity: 100% parameterized queries generated by SQLModel; zero raw string concatenation.
  • P95 Response < 150ms: PyODBC connection pool with fast_executemany enabled for rapid batch transactions.
